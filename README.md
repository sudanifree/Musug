# صفحات فيسبوك الموثقة

إضافة Chrome صغيرة تعرض روابط الصفحات التي تظهر عليها شارة التوثيق في صفحة فيسبوك المفتوحة حاليًا.

## التثبيت

### Chrome

1. افتح `chrome://extensions` في Chrome.
2. فعّل **وضع المطوّر**.
3. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد المشروع، أو اسحب `dist/musug-extension.crx` إلى الصفحة لتثبيت الحزمة.
4. افتح فيسبوك وأعد تحميل الصفحة، ثم اضغط أيقونة الإضافة.

### Firefox

1. افتح `about:debugging#/runtime/this-firefox`.
2. اختر **تحميل إضافة مؤقتة...** وحدد `dist/musug-extension.xpi`.

حزمة XPI المنشأة محليًا غير موقّعة؛ يلزم توقيعها من Mozilla للتثبيت الدائم في إصدارات Firefox العادية.

## إنشاء الحزم

شغّل `python3 scripts/build_extensions.py` لإنشاء ملفي CRX وXPI في `dist/`. يتطلب إنشاء CRX توفر OpenSSL. ينشئ التشغيل الأول مفتاح توقيع محليًا في `dist/extension-signing-key.pem`؛ احتفظ به بأمان واستخدمه عند إنشاء إصدارات لاحقة، ولا تشاركه أو ترفقه بالحزمة.

تقرأ الإضافة تسميات الشارات الظاهرة في الصفحة فقط، ولا تستخدم واجهة Facebook رسمية أو تقدم قائمة شاملة. شارة التوثيق لا تعني أن فيسبوك يضمن موثوقية المنشورات أو المحتوى.
