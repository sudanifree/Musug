# مؤشر رواج Facebook

إضافة Chrome وFirefox تفحص المنشورات وReels الظاهرة في صفحة Facebook الحالية، ثم ترتب ما أمكن قراءته حسب مؤشر تقديري يجمع التفاعلات والتعليقات والمشاركات والمشاهدات مع حداثة النشر. تعمل القراءة محليًا داخل المتصفح ولا ترسل بيانات الصفحة إلى خادم.

هذا **ليس** ترتيبًا عالميًا أو رسميًا، ولا يستطيع قياس الترند خلال آخر دقيقة. يعتمد على الأرقام التي يعرضها Facebook وعلى المنشورات المحمّلة في الصفحة؛ وقد لا تتوفر بعض الأرقام أو روابط المنشورات بسبب تغييرات واجهة Facebook.

## التثبيت

### Chrome

1. افتح `chrome://extensions` في Chrome.
2. فعّل **وضع المطوّر**.
3. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد المشروع، أو ثبّت ملف `dist/musug-extension.crx` إذا كان Chrome يسمح بتثبيت حزم CRX محليًا.
4. افتح Facebook، وحمّل الخلاصة والمنشورات التي تريد فحصها، ثم اضغط أيقونة الإضافة.

### Firefox

1. افتح `about:debugging#/runtime/this-firefox`.
2. اختر **تحميل إضافة مؤقتة...** وحدد `dist/musug-extension.xpi`.

حزمة XPI المنشأة محليًا غير موقّعة؛ يلزم توقيعها من Mozilla للتثبيت الدائم في إصدارات Firefox العادية.

## إنشاء الحزم

شغّل `python3 scripts/build_extensions.py` لإنشاء ملفي CRX وXPI في `dist/`. يتطلب إنشاء CRX توفر OpenSSL. ينشئ التشغيل الأول مفتاح توقيع محليًا في `dist/extension-signing-key.pem`؛ احتفظ به بأمان واستخدمه عند إنشاء إصدارات لاحقة، ولا تشاركه أو ترفقه بالحزمة.
